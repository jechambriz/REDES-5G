# Avance 6 — Memes, 5G y COVID-19

Sitio web estático funcional, sin librerías externas. Incluye 3 PNG y 3 CSV.

## Uso
Abra index.html en un navegador o publique los archivos conservando carpetas.

## GitHub Pages
1. Cree un repositorio público de GitHub.
2. Suba index.html, assets/ y data/ a la raíz.
3. En Settings → Pages, elija Deploy from a branch → main → /(root) → Save.
4. Espere a que GitHub muestre la URL de la página. Entregue la URL y la del repositorio en Canvas.

## Calidad y limitaciones
- Imágenes de meme: reconstrucciones didácticas, no screenshots de originales.
- 233 es muestra de tuits generales, NO memes.
- 50 y 30 son exposición de Ofcom, NO creencia.
- Las conexiones del mapa son conceptuales, NO una red inferida de scraping propio.
- No se publicó a GitHub desde esta entrega.
